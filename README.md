## הרצה מקומית

זה אתר סטטי בלי שלב build. אפשר לפתוח את `index.html` ישירות, או להריץ שרת קטן:

```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

## העלאה ל-Netlify

**אפשרות 1 – גרירה:** להיכנס ל-https://app.netlify.com/drop ולגרור את כל התיקייה.

**אפשרות 2 – מ-GitHub:**
1. ליצור repo חדש ב-GitHub ולדחוף אליו:
   ```bash
   git remote add origin https://github.com/<user>/english-grade4-prep.git
   git push -u origin main
   ```
2. ב-Netlify: **Add new site → Import an existing project** ולבחור את ה-repo.
3. אין צורך ב-Build command. ה-Publish directory הוא `.` (כבר מוגדר ב-`netlify.toml`).

## עריכת החומר

כל התוכן נמצא ב-`js/data.js`: מילים, משפטים, שאלות, סיפורים וימים. אפשר להוסיף מילים או שאלות, וכל המשחקים יתעדכנו אוטומטית.

```
index.html      דף ראשי
css/style.css   עיצוב
js/data.js      כל החומר למבחן
js/engine.js    מנועי המשחקים (חידון, התאמה, זיכרון, איות, מיון...)
js/games.js     הגדרת המשחקים
js/app.js       תפריט וניווט
```
